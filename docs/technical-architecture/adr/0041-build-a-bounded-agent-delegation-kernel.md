# Build a bounded Agent delegation kernel

Nano Notebook will keep its PostgreSQL Durable Runtime and extract a bounded Delegation Kernel from the Research-specific Leader executor. Application code registers fixed Agent Roles, Role Profiles, executor compatibility versions, and legal parent-child relationships. The Kernel owns child Run creation, parent waiting, cancellation propagation, terminal handoff, consumption, and wake-up; Role Executors own model decisions, tools, Checkpoints, and domain outcomes. Sprint 9 permits only `leader -> research`, depth one, one active child, and no child delegation, parallel fan-out, graph execution, dynamic Role, or model-created Agent.

Production model instructions move from inline Go strings into a Git-owned immutable Prompt Catalog. Markdown Prompt Versions and adjacent typed contracts are embedded at build time, registered durably by identity and SHA-256, and assembled into immutable Agent Prompt Sets and Agent Configuration Sets. Leader admission pins one Configuration Set; a Research child carries the same set identity but resolves a Research-specific Role Profile. Infrastructure continuation and retry reuse the pinned versions, while a new user Run may adopt a newer deployment-selected set.

Leader routing becomes a typed intent decision followed by a deterministic Delegation Policy. Router and Research Planner outputs use required function-call contracts and fail closed. A generic delegation record becomes lifecycle authority while Research retains a Role-owned Discovery outcome. Role execution returns a typed Attempt Disposition so retryable work is deliberately requeued with bounded backoff; Lease expiry remains the recovery fallback. Research checkpoints its accepted query plan and each completed Web Search result, providing bounded at-least-once external calls without an exactly-once claim.

This decision preserves ADR 0040's product behavior: only an authorized explicit Source Discovery request can create a private Research child, the child cannot publish or import a Source, and the Leader remains the only Member-facing Run. It supersedes ADR 0040's Research-specific lifecycle storage, copied parent configuration, deadline and recovery mechanics, and executor coupling. Google ADK, LangGraph, and Temporal remain reconsideration options only if registered depth-one delegation stops being the product boundary and graph orchestration, managed multi-Agent deployment, or cross-service long-running workflows become first-class requirements.
